# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public
issue. Instead, email the maintainer at sergei.kulkov@fjfi.cvut.cz with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You should receive a response within 72 hours. Once the issue is confirmed
and patched, a security advisory will be published on this repository.
