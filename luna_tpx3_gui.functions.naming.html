luna_tpx3_gui.functions.naming.migrate_template(cfg) → bool[source]

One-time move of an existing config onto the new default name.

Without this the change would only reach fresh installs, since a saved config always carries an explicit “template”. Runs once (guarded by template_version) and only when the saved value is a superseded default, so a deliberate choice of “{stem}” is never overwritten.
